# Página de redirecionamento

Página estática leve que encaminha visitantes para `https://www.crownbot.com.br/natyvampirinha`.

## Publicar gratuitamente com GitHub Pages

1. Entre em https://github.com e crie uma conta, se ainda não tiver.
2. Clique em **New repository**.
3. Dê um nome, por exemplo `redirect-naty`, marque **Public** e crie o repositório.
4. Clique em **Add file → Upload files** e envie `index.html` (e este `README.md`, se quiser).
5. Clique em **Commit changes**.
6. Abra **Settings → Pages**.
7. Em **Build and deployment**, selecione **Deploy from a branch**.
8. Escolha a branch `main` e a pasta `/(root)`, depois clique em **Save**.
9. Aguarde a publicação e abra o endereço indicado em **Settings → Pages**. Pode levar alguns minutos.
10. Teste no celular e em uma janela anônima antes de divulgar.

## Sobre permanência e segurança

- GitHub Pages é gratuito para repositórios públicos elegíveis, mas não existe garantia de hospedagem “para sempre”; políticas, limites, inatividade ou remoção do repositório podem afetar a disponibilidade.
- Para não perder o link, mantenha a conta e o repositório ativos e guarde uma cópia local do arquivo.
- O destino está escrito no código e não há botão de configuração na página, mas quem tiver acesso de escrita ao repositório poderá alterar o arquivo. Proteja a conta com autenticação de dois fatores e não compartilhe acesso.
- Nenhum redirecionamento garante aprovação por uma plataforma específica nem garante que o destino fique invisível. Plataformas podem analisar o destino final, e ocultá-lo para contornar uma revisão pode violar regras. Use apenas links e destinos permitidos e seja transparente com as pessoas.
- Esta página não coleta formulários nem dados dos visitantes.
